# Política V2 — Etapa 5 / Candidaturas 2026

## Objetivo

Separar claramente três conceitos na interface:

1. pessoa acompanhada pelo sistema;
2. registro de candidatura localizado nos Dados Abertos do TSE;
3. resultado eleitoral disponível.

A presença de uma pessoa em `politica_acompanhamentos` não é tratada como prova de candidatura. Da mesma forma, uma candidatura importada sem resultados não é exibida como "0 votos".

## Situação técnica do registro

O sistema preserva `situacao_registro` exatamente como recebido do arquivo oficial. Valores técnicos iniciados por `#` (por exemplo `#NE`) não recebem interpretação inventada na interface: são apresentados como "Situação ainda não disponibilizada", mantendo o código bruto para auditoria.

## Interface

- Acompanhamento: destaca `Registro TSE 2026` quando existe candidatura oficial vinculada.
- Perfil político: apresenta cargo, partido, número, nome de urna, SQ candidato, sincronização e situação do registro.
- Dados Oficiais: mostra cobertura e última sincronização das candidaturas 2026.
- Sem resultados territoriais: a tela usa `—`/mensagem informativa, nunca converte ausência de resultado em zero votos.

## Prazo 2026

O prazo formal é configurável:

```env
POLITICA_TSE_REGISTRO_2026_TIMEZONE=America/Bahia
POLITICA_TSE_REGISTRO_2026_PRAZO="2026-08-15 19:00:00"
```

A configuração existe para que a interface altere automaticamente o aviso depois do encerramento do prazo, sem hardcode espalhado pelas views.
